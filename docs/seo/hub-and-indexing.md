## Indexing (ranked)
1. Make the page really public at unlock. We 404 until the reel posts, and ISR revalidates every 60 s.
2. Link from already-crawled pages at unlock (hub list, previous chapter's "next" link, footer "latest chapter").
3. Sitemap with an accurate lastmod = the real unlock time (not the build time); robots.txt `Sitemap:` line; submit once in Google Search Console (GSC) and Bing Webmaster Tools.
4. IndexNow ping (Bing, Yandex, Copilot; NOT Google) right after unlock: key file at the site root, POST to api.indexnow.org.
5. Optional: Search Console API sitemaps.submit.
6. Manual GSC "Request indexing" once per new chapter. This is the only direct Google trigger and can't be automated legitimately.
7. RSS/Atom feed /playbook/feed.xml, submitted as a sitemap (+ optional WebSub).
8. Structured data helps understanding, not speed.
9. Link from the reel caption, bio, YT description, LinkedIn and WhatsApp.

**Do not:**
- use the Google Indexing API (JobPosting/BroadcastEvent only)
- use "instant indexer" tools
- make repeated indexing requests

**Expectation:** Bing within hours; Google from hours to days or weeks.
